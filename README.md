# Bankonboarding Shop API

REST API-сервис для управления товарами и расчета стоимости заказов (`Invoice`).

## 🛠 Стек технологий

- Java 21
- Spring Boot 4.1.1 (Web, Data MongoDB)
- MongoDB 7.0
- Docker & Docker Compose
- Lombok

## ⚙️ Требования

Для локального запуска и разработки на вашем ПК должен быть установлен и запущен Docker Desktop.

## 🚀 Быстрый старт

### 1. Настройка окружения

В корне проекта создайте файл `.env` на основе примера:

```bash
cp .env.example .env
```

Укажите в `.env` ваши локальные доступы к базе данных (логин, пароль, порты).

### 2. Запуск проекта через Docker Compose

Единственный поддерживаемый вариант запуска — через Docker Compose.

1. Откройте терминал в корне проекта.
2. Выполните команду сборки и запуска:

```bash
docker-compose up -d --build
```

> Важно: при сборке контейнера Gradle сначала запускает `test`, а затем собирает `bootJar`. Это гарантирует, что микросервис не стартует без валидного набора тестов.
>
> Дополнительно в файле `docker-compose.yml` для сервиса `app` прописано `SPRING_DOCKER_COMPOSE_ENABLED=false`, чтобы избежать конфликта запуска Docker-in-Docker.
