# Bankonboarding Shop API

REST API-сервис для управления товарами и расчета стоимости заказов (`Invoice`).

## 🛠 Стек технологий

- Java 21
- Spring Boot 4.1.1 (Web, Data MongoDB)
- MongoDB 7.0
- Docker & Docker Compose
- Lombok

## ⚙️ Требования

Для локального запуска и разработки на вашем ПК должен быть установлен и запущен Docker Desktop.

## 🚀 Быстрый старт

### 1. Настройка окружения

В корне проекта создайте файл `.env` на основе примера:

```bash
cp .env.example .env
```

Укажите в `.env` ваши локальные доступы к базе данных (логин, пароль, порты).

### 2. Запуск проекта

У вас есть два варианта запуска приложения.

#### Вариант A: Локально для разработки (через IntelliJ IDEA)

Идеально для написания кода и отладки.

1. Убедитесь, что Docker запущен на вашем ПК.
2. Запустите метод `main` в классе `BankonboardingApplication` через IntelliJ IDEA.

Spring Boot Docker Compose автоматически найдет файл `compose-db.yaml` и поднимет только базу данных MongoDB в фоне. Само Java-приложение запустится на вашем ПК.

#### Вариант B: Полностью в Docker (через docker-compose)

Идеально для проверки финальной сборки.

1. Откройте терминал в корне проекта.
2. Выполните команду сборки и запуска:

```bash
docker-compose up -d --build
```

> Примечание: в файле `docker-compose.yml` для сервиса `app` прописано `SPRING_DOCKER_COMPOSE_ENABLED=false`, чтобы избежать конфликта запуска Docker-in-Docker.
